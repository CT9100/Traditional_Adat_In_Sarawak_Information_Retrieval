# User Stories

Format: As a [type of user], I want [goal], so that [reason or benefit].

1. As a student, I want to search for information about traditional Adat in Sarawak, so that I can easily find information for my studies and assignments.
2. As a researcher, I want to browse Adat information by community and category, so that I can identify and understand different traditional practices in Sarawak.
3. As a member of the public, I want to access clear and organised information about selected traditional Adat, so that I can learn about and appreciate Sarawak’s cultural heritage.
