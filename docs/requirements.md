# Requirements

## Functional requirements (what the system must DO)
1. The system shall allow users to search for information about selected traditional Adat in Sarawak using keywords.
2. The system shall display relevant information about traditional Adat including its description, purpose, and cultural significance.
3. The system shall allow users to browse Adat information by community and category, such as marriage, birth, funeral, and traditional ceremonies.
4. The system shall allow users to view detailed information about each selected Adat and its associated cultural practices.
5. The system shall allow users to filter search results based on the selected community or Adat category.

## Non-functional requirements (how the system must PERFORM)
1. The system shall display search results within 3 seconds under normal operating conditions.
2. The system shall provide a user-friendly and responsive interface that works on both desktop and mobile devices.
3. The system shall present information clearly and consistently, using reliable sources to support the accuracy of the cultural information.
